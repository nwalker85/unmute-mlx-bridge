# Support

- **Questions and troubleshooting:** use the
  [Q&A category](https://github.com/nwalker85/unmute-mlx-bridge/discussions/categories/q-a)
  in GitHub Discussions.
- **Ideas and design proposals:** start an
  [Idea discussion](https://github.com/nwalker85/unmute-mlx-bridge/discussions/categories/ideas).
- **Reproducible defects:** open a
  [GitHub issue](https://github.com/nwalker85/unmute-mlx-bridge/issues/new/choose)
  with the relevant template.
- **Performance measurements:** use the performance-report issue template and
  include the complete hardware/configuration context it requests.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md) and report
  privately. Do not disclose a suspected vulnerability in an issue or
  discussion.

This is a community project maintained in spare time. Clear reproductions,
small examples, and exact version information make a response much more likely.
